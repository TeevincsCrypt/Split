## 2. Contract Summary

**File:** `contracts/SplitDistributor.sol`  
**Solidity:** 0.8.28  
**EVM target:** Cancun  
**Dependencies:** OpenZeppelin 5.6.1 (`SafeERC20`, `ReentrancyGuard`)  
**Lines:** ~230  

### Key design properties

- Non-custodial: no funds ever rest in the contract. Every call is a direct payer→recipients sweep via `safeTransferFrom`.
- Atomic: the whole distribution succeeds or the entire call reverts. No partial distributions.
- Ownerless: no admin, no pause, no upgrade, no fee.
- Deterministic rounding: floor for recipients 0..n-2; last recipient gets the remainder so amounts always sum to `totalAmount` exactly.
- `MAX_RECIPIENTS = 50` — gas-tested at 1,817,800 gas for a 50-recipient equal-split distribution (well within any target block gas limit).
- `distributionCount` is incremented (effects) before the transfer loop (interactions), following checks-effects-interactions.
- Event emitted after all transfers, so it only appears in confirmed successful distributions.

The prior Slither run (before the `= 0` explicit initializer) flagged two `uninitialized-local` findings (`sumBps`, `distributed`). The explicit `= 0` initializers were added defensively to eliminate them; they have no semantic effect.
